# Security Policy

## Product vs this repo

helloblue.ai, Groq keys, and `B01.beta` are **out of scope** for this repository. Do not send product secrets or user data here.

## Report a vulnerability in this trainer

- GitHub: **Security → Report a vulnerability** on [HelloblueAI/b01-nuna-lora-trainer](https://github.com/HelloblueAI/b01-nuna-lora-trainer)
- Or email **support@helloblue.ai** with subject `b01-nuna-lora-trainer security`

Please include a repro (untrusted LoRA, path traversal, eval bypass). Do not open a public issue for exploitable bugs.

We aim to acknowledge within 7 days.
